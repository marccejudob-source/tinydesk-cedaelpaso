# 🎵 Ceda el Paso · Tiny Desk Planner

Web para planificar el setlist de nuestro Tiny Desk. Organiza canciones, notas entre temas, y comparte el plan con todo el grupo.

## 🎶 Setlist

1. Una vez al mes
2. Yo te quiero a ti
3. Niña
4. La pasta

## ✨ Funcionalidades

- **Drag & Drop** — Reordena canciones y notas arrastrando (funciona en móvil)
- **Notas entre canciones** — Apunta qué decir entre tema y tema
- **Timeline visual** — Barra de progreso con el tiempo total del set
- **Modo presentación** — Vista limpia para ensayo/grabación
- **Exportar a PDF** — Descarga el setlist completo
- **Exportar/Importar JSON** — Comparte el plan con el grupo

## 📱 Cómo usar

### Opción 1: Abrir directamente
Simplemente abre el archivo `index.html` en tu navegador.

### Opción 2: GitHub Pages
1. Sube este repositorio a GitHub
2. Ve a **Settings → Pages**
3. Selecciona la rama `main` y la carpeta `/ (root)`
4. Tu web estará disponible en `https://tu-usuario.github.io/TinyDesk-CedaElPaso/`

## 🤝 Compartir con el grupo

1. **Con GitHub Pages**: Comparte el enlace por WhatsApp/Telegram
2. **Con JSON**: Exporta tu setlist (botón 📤), envía el archivo `.json` al grupo, y los demás lo importan (botón 📥)
3. **Con el archivo**: Simplemente comparte la carpeta o el archivo HTML

## 🛠 Tecnología

- HTML + CSS + JavaScript puro (sin frameworks)
- Datos guardados en localStorage
- PDF con html2canvas + jsPDF (CDN)
- Sin necesidad de servidor
